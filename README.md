# Система диагностики болезни Паркинсона по голосовым характеристикам
Система машинного обучения для обнаружения болезни Паркинсона на основе анализа акустических параметров голоса. Проект включает сравнительный анализ различных алгоритмов классификации.

## Функциональность
* Анализ датасета с голосовыми характеристиками пациентов  
* Предобработка и нормализация данных  
* Обучение множества алгоритмов классификации  
* Сравнительная оценка эффективности моделей  
* Визуализация результатов и метрик качества  

## Технологии
Python 3.8+  
Scikit-learn - машинное обучение  
Pandas, NumPy - обработка данных  
Matplotlib, Seaborn - визуализация  
XGBoost - градиентный бустинг  

## Особенности реализации
* Предобработка данных  
* Масштабирование признаков до диапазона [-1, 1]  
* Стратифицированное разделение для сохранения баланса классов  
* Визуализация корреляций между признаками  
* Валидация моделей  
* Тестовый набор: 20% данных  
* Стратификация по целевому признаку  
* Сравнение train/test accuracy для выявления переобучения  
* Парные графики распределений признаков  
* Heatmap корреляционной матрицы  
* Сравнительные диаграммы точности моделей  

## Лицензия
Проект предназначен для образовательных и исследовательских целей. Для клинического использования требуется дополнительная валидация и сертификация.
